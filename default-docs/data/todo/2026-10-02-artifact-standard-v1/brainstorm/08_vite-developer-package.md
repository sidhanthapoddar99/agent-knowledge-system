## A small Vite package shipped with the library

The owner clarified that the preview is particularly for **people developing the library**. The library should ship a small package of Vite code giving authors a methodology for viewing, developing and testing components.

The intended developer workflow includes:

- Browse components by collection, category and style.
- Inspect artifacts, charts, tables, SVGs and icons.
- Run examples and adjust inputs to see component behavior.
- Inspect source, typed inputs and usage examples.
- Compare light/dark modes, motion variants and reduced-motion behavior.
- Play sample audio in narrated examples.
- Build the preview and representative browser embeds without the engine.

The preview should be small and useful as an authoring tool, not merely a screenshot page. Installation/start/build instructions and a clear directory/example convention are part of the methodology.

The owner asked that examples and audio ship with the library. Audio format, sample selection, licensing/provenance and packaging remain design details. Production generated voice/audio storage remains a later engine concern.
