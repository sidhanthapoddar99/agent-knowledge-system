# agent-ks 0.1.2 — Verified official Latest discovery

The installer and native updater discover updates through GitHub's official Latest release endpoint.

## Changed

- Validate the exact stable numbered CLI tag, publication state, platform archive, and checksum asset before choosing a release.
- Fall back to bounded numeric release-history selection when Latest discovery is missing or invalid.
- Keep download-integrity failures terminal; checksum, archive, executable-version, pin, downgrade, cooldown, locking, and atomic replacement protections remain in place.

CLI testing, five-platform builds, and publication run in one numbered-tag workflow. Engine and plugin versions remain tag-only.
