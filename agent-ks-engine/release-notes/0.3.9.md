# 0.3.9 — the skills are re-cut by domain; setup gets its own skill

No engine change beyond the version number. This release carries the plugin:
`agent-ks` goes from 0.9.1 to 0.10.1. The skills are cut one per domain, setup and
configuration get a skill of their own with a full reference per topic, the blog
gets its own skill, and two command names change.

**No content migration. `MIN_CONTENT_VERSION` stays at `0.2.0`.** Nothing on disk
needs changing — set `engine_version: "0.3.9"` in `site.yaml` when you upgrade.

Plugin: **`agent-ks` 0.10.1** — see below.

**Engine `0.3.9` · floor `0.2.0` · plugin `0.10.1`** — released 2026-09-04, tag `v0.3.9`.

## Upgrade

No migration scripts. The whole chain is:

```bash
git pull
./start doctor          # full build — confirms nothing broke
# then, in site.yaml:
#   engine_version: "0.3.9"
```

Set `engine_version` last, as always. Then update the plugin:

```
/plugin marketplace update sids-plugin-marketplace
/plugin install agent-ks@sids-plugin-marketplace
/reload-plugins
```

**Two slash commands are renamed.** `/agent-ks-init` is now `/agent-ks-config`,
and `/agent-ks-add-section` is now `/agent-ks-config section <name>`. The old
names stop working the moment the plugin updates. A `CLAUDE.md` written by the old
init names the old skills; the new one is in the config skill's `assets/`.

## What's new

**Plugin `agent-ks` 0.10.1** (from 0.9.1)

- `agent-ks-config` is new. It owns everything done once, or once in a long
  while: a new project from the starter template, a new top-level section,
  `site.yaml`, `navbar.yaml`, `footer.yaml`, `.env`, path aliases, themes and
  `theme.yaml`, layout styles and custom layouts under `LAYOUT_EXT_DIR`, custom
  pages and their YAML, and format migrations. Eight references, one per topic,
  each complete enough to do the job without the user guide open. It replaces
  `agent-ks-init` and `agent-ks-add-section`.
- `agent-ks-docs` covers pages inside a docs section only: prefixes, folder
  settings, frontmatter, links, diagram and artifact pages, images, moves. Site
  config, themes, the blog and migrations left it.
- `agent-ks-blog` is new, one file: the dated filename, frontmatter, a post's
  assets, the index, the blog commands.
- `agent-ks-logs` is renamed `agent-ks-issue-logs`. Content unchanged.
- `agent-ks-qna` is new (plugin 0.10.1): scope a subtask or a plan stage by
  question and answer before a long run. It names the seven things a work order
  must answer and where each goes, takes a dictated story or runs an interview
  in rounds, plays the draft back, and writes the answers into the subtask's own
  sections with the reason behind every decision. The issues skill points to it
  from the work-order rules.
- Ten skills. The user guide's plugin page and every pointer in the repo name
  the new set.
