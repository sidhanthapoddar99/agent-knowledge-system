# Rounds

- [the seven-surface inventory](./010_surface-inventory.md) — no surface returned a fatal
  loss, but 22 of 46 claim-checks against the architecture notes came back false or
  partly-true, clustered in the performance table and the "what we must replace" list;
  islands, custom-tags and MDX are budgeted for removal and do not exist. Ten defects in
  the *current* code found in passing.
- [the four deep questions](./020_deep-questions.md) — JIT rendering works (0.54 ms p50
  with a warm cache, measured on a Go server built for the audit); a B-tree earns nothing
  at this corpus size and persistence is slower than re-deriving; CSS and theme
  customization survives intact; and the trigger that justifies the whole migration has a
  one-day fix that four sibling files already use.
