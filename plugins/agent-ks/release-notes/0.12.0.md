# 0.12.0 — Standalone native toolkit integration

The plugin now teaches agents to use the separately installed Rust `agent-ks` toolkit. Its skills and templates remain usable across Claude Code, Codex, and other skill-compatible agents, while content operations no longer depend on a JavaScript dispatcher bundled with the plugin.

## What changed

- Replaced the plugin-bundled command surface with instructions for the standalone native CLI.
- Added native toolkit installation, explicit project selection, updater, and command-discovery guidance.
- Kept the two plugin manifests synchronized for Claude Code and Codex.

## Compatibility

Install the separately released `agent-ks` CLI when command execution is needed. The skills themselves remain plain files and do not require the CLI merely to be read.
