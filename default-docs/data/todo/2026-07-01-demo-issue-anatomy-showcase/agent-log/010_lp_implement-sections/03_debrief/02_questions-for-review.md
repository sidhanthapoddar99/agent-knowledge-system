# Two calls the run did not take

1. **Should a section be able to opt out of sub-doc URLs?** `comments/` has no
   sub-doc pages and is special-cased. Either that is a section property or the
   special case stays. Not a blocker; it costs one field.

2. **Does the depth cap belong to the loader or to the section?** Today it is
   global. A `plans/` folder is two levels by construction and could say so.

Both are design calls with a defensible recommendation, so they are recorded
here rather than parked — the run kept going.
