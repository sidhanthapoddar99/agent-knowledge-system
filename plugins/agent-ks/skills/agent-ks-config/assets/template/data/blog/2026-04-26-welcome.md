# Welcome

This is the sample post that ships with the template. Posts are flat markdown
files under `data/blog/`. Each file is named `YYYY-MM-DD-<slug>.md`. Keep the
date in the filename and the `date:` field in the frontmatter the same.

## Add a post

Create a new file alongside this one:

```
data/blog/2026-05-01-my-first-real-post.md
```

Give it at least `title`, `description` and `date` in the frontmatter. The blog
index at `/blog` updates by itself.
