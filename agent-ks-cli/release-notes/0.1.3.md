# agent-ks 0.1.3 — Native viewer lifecycle

The Rust CLI owns viewer startup, builds, dependency installation, framework updates, content-version checks and server control.

## Added

- `agent-ks ps` reports dev and preview servers in the selected framework checkout.
- `agent-ks stop` stops both server types; supply `dev` or `preview` to select one.
- Native Windows bootstrap installation verifies the numbered release checksum and executable version.

## Changed

- `agent-ks start` runs Bun or npm and Astro server controls directly, without calling a framework launcher script.
- Framework `start` and `start.cmd` wrappers find the CLI, offer installation if missing, and forward `CONFIG_DIR` from `.env` with an environment override.
- Foreground starts retain server ownership: interruption stops an owned server, including late registration during startup, while attaching to an existing server leaves it running.
- CLI help and documentation describe native build, doctor, update, logs, cleanup and package-script commands.

Update the CLI to this version before using the framework's bootstrap wrappers. The viewer still requires Bun or Node.js with npm; content commands remain standalone.
