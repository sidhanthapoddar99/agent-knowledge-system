**These are the notes, subtasks and decisions this design changes. ## 01 The video issue

| File | Change |
|---|---|
| [issue.md](../../issue.md) | **Goal:** a video is an independent artifact, one `NN_<slug>.video.yaml` file (about 7 KB for three minutes; the check warns past 10 KB), played live in the browser from library components, with a generated voiceover; no rendered video file of any kind, cached or stored. **Done when:** the player spike and the voice spike are judged good enough (replaces "a second spike (grid scenes, cues and the first widgets)"). **Scope in:** the video artifact format and its schema, the standalone player page, the player, the layout system and its diagnostics, the item kinds, PowerPoint-level motion, the voice helper, the pronunciation list and the audio store, the video component categories, the authoring skill. **Scope out:** replace "motion-graphics-level animation (Remotion or HyperFrames style keyframing)" with "film-level motion: free keyframing, character animation, 3D"; add "a markdown embed in the first version (it comes later)". Drop "the markdown video format" |
| [settings.json](../../settings.json) | Rewrite `title` and `description` for the video artifact: a YAML file of slides, narration and actions, played live; library-driven; voice by Kokoro through a helper |
| [01/03 The spike](../../notes/01_initial_discussion/03_the-spike.md) | Add that the markdown format is retired and that the spike's narrator carries over as the browser-voice fallback |
| [01/04 A proper video engine](../../notes/01_initial_discussion/04_video-engine.md) | Replace the proposed design (cues in HTML comments, a widget library built into the engine) with a pointer to the new design. The user's decisions in its section 04 stay |
| [01/05 Narration audio](../../notes/01_initial_discussion/05_narration-audio.md) | Model: Kokoro-82M v1.0 timestamped, 8-bit, with misaki-rs (MIT) built without its `espeak` feature, run by `agentks-voice`. Unknown words are an error, fixed by the pronunciation list in `config/video.yaml` or the video's `pronounce:`. Clips: one per beat, Ogg Opus mono 24 kHz at 24 kbit/s (not 48). Delivery: one joined stream per video. Voice choice: the video's `voice`, else `config/video.yaml`, else the browser. Publishing: ship each video's stream |
| [01/06 Caching](../../notes/01_initial_discussion/06_caching.md) | Audio moves out of the build cache into a machine-wide store, `~/.agentks/audio/`, keyed by content, so every project and clone shares it. The key adds the pronunciation entries and the helper's version, and leaves out the playback rate. Joined streams live beside the clips. Add `tools/agentks-voice/<version>/` |
| [01/07 Libraries and reusable elements](../../notes/01_initial_discussion/07_libraries-and-reusable-elements.md) | Replace "the video widgets themselves are built into the binary" with the split in [library components](./08_library-components.md#01-who-owns-what). Components are named in typed fields of the video file, not in cues. Library elements are used only in video artifacts and HTML artifacts |
| [01/08 Relation to the engine migration](../../notes/01_initial_discussion/08_relation-to-the-engine-migration.md) | "Reading the markdown into scenes, beats and cues" becomes "compiling the `.video.yaml` file". The player is its own package, `apps/packages/agentks-video`, wrapped by an island. "What can start now" becomes the two spikes in the new repository, not work in today's engine |
| [01/09 Open questions](../../notes/01_initial_discussion/09_open-questions.md) | 01: two spikes, player and voice. 02: Kokoro-82M, pending sidhantha's listening test. 03: no cues; actions sit in the YAML beside their narration. 04: the player is framework-free TypeScript |
| [01/01 Index](../../notes/01_initial_discussion/01_index.md) | Once agreed, this brainstorm graduates to a new notes group, and the index points at it |

Section 16: the default library's content follows [the day-one set](./08_library-components.md#08-the-day-one-set). This also settles [the migration's comment 003](../../../2026-09-29-rust-core-engine-migration/comments/003_2026-09-30_library-components-layout.md) |
| [04/04 Templates and init](../../../2026-09-29-rust-core-engine-migration/notes/04_ecosystem/04_templates-and-init.md) | The starter template ships `config/video.yaml` with the default voice and a `pronounce:` entry for "agentks" |
