# agent-ks 0.1.2 — Verified cli-latest update discovery

This release makes the installer and native updater use the moving `cli-latest` tag as their fast path without treating that pointer as a version or download source.

## Changed

- Update discovery resolves `cli-latest` to a commit, reads the CLI package version from `Cargo.toml` at that immutable commit, and requires the matching numbered stable release.
- The numbered tag must resolve to the same commit, and the release must contain the platform archive plus `SHA256SUMS` before installation begins.
- A missing, stale, malformed, draft, prerelease, unpublished, or mismatched alias discovery falls back to the bounded stable release-history lookup.

## Safety

Downloads still come only from the immutable `agent-ks-cli-vX.Y.Z` release. Checksum, archive, executable-version, downgrade, pin, cooldown, locking, and atomic replacement protections are unchanged. Download-integrity failures remain terminal and never fall back to an older release.
