# Welcome

This is the first page of **your** documentation. The `/agent-ks-config`
command copied this file in. Replace it with your own content.

## What's already wired up

- A **Docs** section at `/docs` (this file)
- A **Blog** at `/blog` with a sample post
- An **Issues** tracker at `/issues`
- The framework's own **User Guide** at `/user-guide`. The framework keeps it
  current. Read it when you forget how something works

## Next steps

- Open `data/docs/05_getting-started/01_welcome.md` and edit this file
- Add another section: create `data/docs/10_<your-section>/` with a `settings.json`
- Customise the home page via `data/pages/home.yaml`
- Swap the placeholder logo in `assets/` for your own

The `NN_` prefix on file and folder names sets the order. The URL drops it. For
example, `05_getting-started/01_welcome.md` is served at
`/docs/getting-started/welcome`.
