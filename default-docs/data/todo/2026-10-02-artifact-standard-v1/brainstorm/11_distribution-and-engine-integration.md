## Publishing the library and updating the engine

The intended outcome includes a published reusable library. Packaging should make browser consumption practical, with its complete code/assets, examples, themes, dependencies and licenses.

The exact distribution target, release version and publication procedure will be defined later. This idea capture does not publish a package or tag.

After the library and preview are ready, engine work can integrate component resolution, artifact loading, bundle output, HTML embedding, narration/branching and publishing paths. The existing HTML and video issues remain related work, rather than being silently replaced or merged.
