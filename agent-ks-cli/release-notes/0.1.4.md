# agent-ks 0.1.4 — Move files that carry their own links

A patch release that fixes `agent-ks move` for the most common case: moving a page that links to its neighbours.

## Fixed

- `agent-ks move` failed with `Not a directory (os error 20)` when the moved Markdown file contained relative links that needed rewriting. The command wrote the rewritten file to a path with a trailing slash. It rolled every change back, so no content was lost, but the move never happened. Moves of files without their own links, and dry runs, were unaffected.

Update with `agent-ks update`. Content and config formats are unchanged.
