# agent-ks 0.1.0 — Native knowledge toolkit

Install the standalone `agent-ks` binary using the curl installer in the repository README. The accompanying plugin is version 0.12.0. It supplies skills and templates and requires the standalone toolkit to be installed separately; the CLI has its own version and GitHub release assets.

Run from the documentation root. Config resolution is `--config-dir PATH`, then `AGENTKS_CONFIG_FOLDER`, then `./config`. Relative paths are evaluated from the working directory. The config directory's parent is the project root. A missing config directory is an error. The CLI does not read a framework `.env` to select content.

The native toolkit provides issue queries and scaffolding, docs and blog queries, validators, link-aware moves, image optimization, git metadata, and theme tokens. Search adds literal matching, context lines and result limits. `overview`, `issue tree`, and `issue context` help agents navigate large projects. Every group and command has help; `help --json` returns the command catalog.

`agent-ks start` launches the site viewer and clones the framework when missing. The viewer requires Node.js or Bun and Git for the first clone. Git commands require Git; image optimization requires ImageMagick. Other toolkit commands run without an interpreter.

The Linux binaries use musl. Assets also cover macOS Intel/Apple Silicon and Windows x64. Each archive has a checksum in `SHA256SUMS`.

CLI releases use the `agent-ks-cli-vX.Y.Z` namespace. The installer and updater select only that namespace, so engine and plugin releases cannot be mistaken for CLI downloads.

`agent-ks update` installs a CLI release manually. The installer adds a silent shell-startup updater with a shared five-hour cooldown. Ordinary commands do not check for updates. `init` prints setup for Bash, Zsh, Fish and PowerShell. Pins and disable controls are supported, with checksum/archive/version verification before replacement.
