## The fix

The diagram container centers its content with `text-align: center`. That works
for mermaid, graphviz and excalidraw because they render an inline `<svg>`. The
draw.io viewer is different: it writes a fixed pixel width onto its own block
`<div>` (`.drawio-host`), and `text-align` never moves a block box. The
stylesheet did carry a centering rule for it, but that rule flex-centered an
assumed *inner* child — the sized host itself stayed left.

The fix is auto side margins on `.drawio-host`, folded into the existing rule in
`src/styles/markdown.css`.

**The symptom this fixes:** a page renders an embedded `.drawio` diagram pinned
to the left edge of its grey diagram box, with all the empty space on the right —
most visible on wide or full-width themes.
