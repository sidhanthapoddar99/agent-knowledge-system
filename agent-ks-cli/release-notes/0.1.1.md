# agent-ks 0.1.1 — Windows-safe image link rewriting

This patch makes image conversion link rewriting work consistently on Windows while preserving the native toolkit introduced in 0.1.0.

## Fixed

- `agent-ks img --rewrite-links` now recognizes the same file when Windows presents its content root in extended-length canonical form and the image input in ordinary lexical form.
- Rewritten document links remain filesystem-relative with forward slashes, and image backups remain unchanged.

## Verification

The physical-path identity regression test and the existing image conversion integration test cover the fix. The release matrix validates Linux x86_64/ARM64, macOS Intel/Apple Silicon, and Windows x64 before publishing binaries and `SHA256SUMS`.
