# Memory index

Entry point for this issue's agent memory — **one line per topic, and no content
here at all.** Read this first, then open only what the task needs.

- [Gotchas](gotchas.md) — theme and layout traps hit while building the fixture
- [Loader facts](knowledge/loader-facts.md) — what is true and binding about the reader
- [How we got here](history/origins.md) — what was tried, and what was parked

## Two things this index deliberately does NOT have

**No "current state" section.** What is left, in what order, and who is waiting is
the [active plan's](../plans/02_hardening-the-edges/overview.md) job. An index
that grows a state section competes with the plan and loses silently, because
nothing tells a reader which of the two is current.

**No decisions file.** Decisions live in the issue's `notes/` — they outlive the
run, and a decision recorded only in an agent's working state is a decision that
gets re-litigated when the memory is corrected in place.
